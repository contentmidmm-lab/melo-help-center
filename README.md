# Melo Help Center

Melo App Feature Guide Version 2.0 ကို အခြေခံထားသည့် mobile-friendly အသုံးပြုပုံလမ်းညွှန် website ဖြစ်ပါသည်။

## GitHub Pages ပေါ်တင်ရန်

1. GitHub မှာ repository အသစ်တစ်ခုဖန်တီးပါ။
2. ဒီ folder ထဲက file အားလုံးကို repository ရဲ့ `main` branch သို့ upload လုပ်ပါ။
3. Repository **Settings → Pages → Build and deployment** မှာ Source ကို **GitHub Actions** ရွေးပါ။
4. Upload ပြီးနောက် **Actions** tab မှ deployment ပြီးဆုံးသည်အထိ စောင့်ပါ။
5. Published URL ကို Settings → Pages မှာ ကြည့်နိုင်ပါသည်။

Website သည် build command သို့မဟုတ် server မလိုသော static site ဖြစ်ပါသည်။
